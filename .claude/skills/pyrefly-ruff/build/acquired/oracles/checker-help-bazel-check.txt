Entry point for Bazel integration

Usage: pyrefly bazel-check [OPTIONS] --output <FILE> <INPUT_PATH>

Arguments:
  <INPUT_PATH>  Path to Bazel input JSON

Options:
  -j, --threads <THREADS>            Number of threads to use for parallelization. Setting the value
                                     to 1 implies sequential execution without any parallelism.
                                     Setting the value to 0 means to pick the number of threads
                                     automatically using default heuristics [env: PYREFLY_THREADS=]
                                     [default: 0]
  -o, --output <FILE>                Path to output JSON file containing Pyrefly type check results
      --color <COLOR>                Control whether colored output is used [env: PYREFLY_COLOR=]
                                     [default: auto] [possible values: auto, always, never]
      --min-severity <MIN_SEVERITY>  Minimum severity level for errors to be displayed. Errors below
                                     this severity will not be shown. Defaults to "error" [default:
                                     error] [possible values: ignore, info, warn, error]
  -v, --verbose                      Enable verbose logging [env: PYREFLY_VERBOSE=]
  -h, --help                         Print help
